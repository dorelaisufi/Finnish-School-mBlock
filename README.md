# Finnish School mBlock

## What is mBlock?

mBlock is a **programming platform** that helps us learn coding and robotics. We use it in ICT lessons to program mBot2.

## How Do We Connect mBot2 to mBlock?

1. Open mBlock.
2. Connect mBot2 to the computer using USB or Bluetooth.
3. Select CyberPi or mBot2 in the Devices section.
4. Click Connect and choose the device.

## Block Programming vs Python

*Block programming* uses colourful blocks that we drag and connect together.

**Python programming** uses written code to give instructions.

## How Do We Run a Program?

We create our program in mBlock and connect the robot. We can use Live mode to run commands or Upload mode to save a program to the robot.

## Why is mBlock Useful?

mBlock makes programming easier to understand. We can learn how robots work and practise coding.

## What We Learn

- How to connect mBot2.
- How to use coding blocks.
- How to run programs.
- How to control a robot.
